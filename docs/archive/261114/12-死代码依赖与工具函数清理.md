# 12 · 死代码、依赖与工具函数清理

- 优先级：P3
- 类型：清理 / 可维护性
- 依赖：03（小猫拖动绑定移除后才能删 `useDraggable`）
- 影响文件：`components/PushWall.vue`、`composables/useDraggable.ts`、`package.json`、`data/site.ts`、`assets/css/main.css`、`composables/useTheme.ts`、`utils/time.ts`、若干页面/组件

## 问题

项目里积累了一些未使用或重复的代码：

- `components/PushWall.vue`：没有任何页面引用（`/push` 自己实现了列表）。
- `composables/useDraggable.ts`：没有任何引用（CatChat 的绑定在编号 03 中移除）。
- `@vueuse/motion`：`package.json` 中的 devDependency，全项目无使用。
- `data/site.ts` 的 `nextAnniversary`、`nextAnniversaryLabel`、`curtainHint` 未使用。
- `assets/css/main.css` 的 `.curtain-soft`、`.sunbeam`、`.sun-rays`、`.dust` 及对应 keyframes 是旧封面遗留。
- `useTheme` 在布局和切换器中各调用一次，`onMounted` 会重复 apply。
- 多处重复的时间格式化函数。
- `pages/calendar.vue` 对 `marked.parse()` 的返回值直接断言为 string。

## 方案

### 1. 删除死代码

- 删除 `components/PushWall.vue`。
- 删除 `composables/useDraggable.ts`。
- 删除 `assets/css/main.css` 中 `.curtain-soft`、`.sunbeam`、`.sun-rays`、`.dust` 以及 `@keyframes sunrise`、`rayShine`、`floatDust`。
- 删除 `data/site.ts` 中未使用的三个字段（保留 `curtainGreeting`）。

删除前先全局 `grep` 确认没有引用。

### 2. 移除未用依赖

```bash
npm uninstall @vueuse/motion
```

会同步更新 `package.json` 与 `package-lock.json`。

### 3. 主题初始化去重

`composables/useTheme.ts` 增加模块级标记：

```ts
let initialized = false
onMounted(() => {
  if (initialized) return
  initialized = true
  // 读取 localStorage 并 apply
})
```

仍保留多个组件调用 `useTheme()` 的能力，但只执行一次初始化。

### 4. 时间格式化收敛

新增 `utils/time.ts`：

```ts
export function formatShortDateTime(at: number): string   // M/D HH:mm
export function formatFullDateTime(at: number): string    // YYYY/MM/DD HH:mm
export function formatRelative(at: number): string        // 刚刚 / N 分钟前 / … / 日期
```

替换：

- `components/NoteWall.vue` → `formatShortDateTime`
- `pages/memo.vue` → `formatShortDateTime`
- `pages/dislikes.vue` → `formatFullDateTime`
- `pages/push.vue` → `formatRelative`
- 已删除的 `PushWall.vue` 不再处理

保持输出格式与现在完全一致。

### 5. `marked` 返回值类型

`pages/calendar.vue:99-102` 改为：

```ts
const parsed = marked.parse(raw)
return typeof parsed === 'string' ? parsed : ''
```

避免把 `Promise<string>` 误当字符串。

### 6. 小猫共享历史

`cat_messages` 不区分身份是现有产品行为（小猫是「尚锦」，主要陪在野）。本批次**不拆分**，在 `docs/features.md` / `architecture.md` 中明确说明即可。

## 风险与回滚

- 删除文件前务必确认无引用；可通过 `git revert` 恢复。
- 时间格式化重构属于纯替换，建议逐页对比截图/文本。
- 若之后想恢复小猫拖动，可重新引入 `useDraggable` 并同步面板位置，不在本批次范围。
