# 10 · 封面动画性能

- 优先级：P2
- 类型：性能
- 依赖：无
- 影响文件：新增 `composables/useCover.ts`、`components/CurtainIntro.vue`、`layouts/default.vue`

## 问题

未解锁停留在首页时，同时存在两个全屏动画循环：

- `layouts/default.vue:17-18` 始终渲染背景 `MeteorCanvas` 或 `SakuraCanvas`；
- `components/CurtainIntro.vue:75` 又渲染一个交互版 `MeteorCanvas`。

两个 Canvas 都在跑 `requestAnimationFrame`，移动端耗电、低端机掉帧。

## 方案

用一个模块级单例记录封面是否可见，封面显示时卸载布局层 Canvas。

### 1. 新增 `composables/useCover.ts`

```ts
import { ref } from 'vue'

const coverVisible = ref(false)

export function useCover() {
  return {
    coverVisible,
    showCover: () => (coverVisible.value = true),
    hideCover: () => (coverVisible.value = false),
  }
}
```

### 2. 改造 `CurtainIntro.vue`

- `onMounted(() => showCover())`
- `finish()` 的 700ms 定时器里调用 `hideCover()`（此时封面正在淡出，布局背景开始接管）
- `onUnmounted(() => hideCover())` 兜底

### 3. 改造 `layouts/default.vue`

```vue
<ClientOnly>
  <SakuraCanvas v-if="!coverVisible && current === 'sakura'" />
  <MeteorCanvas v-else-if="!coverVisible" :interactive="true" />
</ClientOnly>
```

- 封面可见时，布局层不渲染 Canvas；
- 封面消失后，布局层按当前主题挂载对应 Canvas；
- 非首页没有封面，`coverVisible` 为 `false`，行为不变。

## 验收标准

- [ ] 未解锁首页时，页面中只有封面一个 `<canvas>`，只有一个动画循环。
- [ ] 解锁后，封面 Canvas 卸载，布局背景 Canvas 正常出现。
- [ ] 星空 / 樱花主题切换后，背景 Canvas 类型正确。
- [ ] 从内页返回首页、锁定、再次解锁，Canvas 数量始终正确，无残留 RAF。
- [ ] 移动端封面期间 CPU/耗电明显下降（主观验证即可）。

## 风险与回滚

- `coverVisible` 是全局单例；若封面异常未触发 `finish`，`onUnmounted` 兜底。
- 回滚：移除 `v-if="!coverVisible"` 条件与 `useCover` 调用。
