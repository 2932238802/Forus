## 方案

### 1. 根 `README.md`

- 删除 `/diary` 与 `diaries.sql`。
- 功能列表补齐：日历（隐藏）、又推又推（隐藏）、给未来的信、小猫 AI、想你了、庆祝彩蛋、双主题。
- 图片墙描述改为「列表 + Lightbox」，不再说瀑布流。
- 安全说明更新：
  - 信件与小猫对话已收口到服务端（service_role）；
  - Storage 删除收口到服务端；
  - 解锁接口有限流；
  - 剩余风险：其他表仍 anon 直连、media 公开读。
- 数据库脚本表更新为 `docs/database.md` 的完整顺序，不再重复维护两份。
- 目录树补 `docs/`、`server/api/letters`、`server/api/media` 等。
- 更新「后续规划」：信件已完成，PWA / 地图足迹等保留。

### 2. `AGENTS.md`

- 修正 composable 状态描述：只有 `usePassphrase` / `useIdentity` / `useTheme`（以及新增的 `useCover` / `useToday`）是模块级单例。
- 修正 runtimeConfig 字段：`passphrase`、`authSecret`、`catApiBase`、`catApiKey`、`catModel`、`supabaseServiceKey`。
- 补充新目录/文件：
  - `server/api/letters/*`、`server/api/cat-messages.get.ts`、`server/api/media/delete.post.ts`；
  - `server/utils/supabase-admin.ts`、`require-unlock.ts`、`rate-limit.ts`、`safe-compare.ts`；
  - `composables/useMediaUpload.ts`、`useCover.ts`、`useToday.ts`；
  - `utils/storage.ts`、`utils/time.ts`、`utils/errors.ts`；
  - `supabase/upgrade-*.sql`。
- 路由表补充 `/calendar`、`/push` 隐藏说明。
- 验证命令更新为 `npm run build`、`npm run typecheck`、`npm run test`、`npm run lint`。
- 指向 `docs/README.md` 作为主文档。
